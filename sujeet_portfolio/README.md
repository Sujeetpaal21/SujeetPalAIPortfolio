## ⚡ Key Implemented Systems

1. **3D AI Core (Three.js):** Central icosahedron neural sphere with orbiting data nodes and particle cloud.
2. **Holographic Digital ID Card:** Features Sujeet's authentic portrait, Soul AI designation, NIT Jamshedpur credentials, and live status.
3. **Interactive AI Agent Lab:** 8-stage visual reasoning loop with live execution simulation and terminal logs.
4. **Vector Database Projection (RAG Lab):** 2D embedding space visualization with nearest-neighbor cosine similarity calculation.
5. **Data Science Lab ("Ask The Data"):** Natural language query parser with dynamic SVG chart synthesis and statistical takeaways.
6. **Career Timeline:** Structured in *Problem → Approach → Technology System → Outcome* format for Soul AI, Upstox, ThinkCogent, and Lupin India.
7. **Ask Sujeet AI Assistant:** Conversational drawer modal backed by Sujeet's resume and project knowledge base.
8. **Synthesized Audio Engine:** Built-in Web Audio API sound effects with mute toggle.

## 🚀 How to Run Locally

1. Extract the ZIP file on your computer.
2. Double-click **`index.html`** to open it directly in any modern browser (Chrome, Edge, Safari, Firefox).
3. No server or build setup required!

---

## 🌐 How to Deploy for Free

### Option 1: GitHub Pages
1. Create a new GitHub repository named `portfolio` at `https://github.com/Sujeetpaal21`.
2. Push or upload the contents of this folder.
3. Go to **Settings > Pages > Branch: `main`** and click **Save**.
4. Your website is live in 60 seconds!

### Option 2: Vercel / Netlify
1. Go to [vercel.com](https://vercel.com) or [netlify.com](https://netlify.com).
2. Drag and drop the unzipped `sujeet_portfolio` folder.
3. Get an instant live HTTPS link!
